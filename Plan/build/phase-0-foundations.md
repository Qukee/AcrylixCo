## Task 4: Tailwind theme tokens

The prototype committed to a clear typographic and colour direction (Bricolage Grotesque + Fraunces + JetBrains Mono, dark UI panel + cream canvas, accent #d6c294). The storefront will decide its own visual language in Phase 2, but Phase 0 sets up the **token surface** so future work plugs into a consistent system.

**Note on Tailwind version**: `create-next-app@latest` installs **Tailwind v4**, which uses CSS-based configuration via `@import "tailwindcss"` and `@theme` directives in `globals.css` — there is no `tailwind.config.ts`. All theme tokens live in CSS.

**Files:**
- Modify: `site/src/app/globals.css`
- Modify: `site/src/app/layout.tsx`

- [ ] **Step 1: Replace `globals.css`**

Path: `site/src/app/globals.css`

```css
@import "tailwindcss";

/*
 * Theme tokens. Tailwind v4 reads `@theme` blocks at build time and emits the
 * corresponding utilities (e.g. `bg-cream-100`, `text-ink-900`, `font-serif`).
 * Source: https://tailwindcss.com/docs/theme
 */
@theme {
  /* Fonts — backed by next/font CSS variables, set on <html> in layout.tsx */
  --font-sans: var(--font-sans-family), system-ui, sans-serif;
  --font-serif: var(--font-serif-family), Georgia, serif;
  --font-mono: var(--font-mono-family), ui-monospace, monospace;

  /* Cream — warm neutral storefront base */
  --color-cream-50: #faf6ec;
  --color-cream-100: #f3ede0;
  --color-cream-200: #ece5d3;
  --color-cream-300: #dcd3bd;
  --color-cream-400: #c8c2b3;

  /* Ink — text on cream */
  --color-ink-900: #2c2920;
  --color-ink-700: #5a564d;
  --color-ink-500: #8a8472;

  /* Accent — gold, matches prototype */
  --color-accent: #d6c294;
  --color-accent-dark: #a99868;
}

html,
body {
  background: var(--color-cream-100);
  color: var(--color-ink-900);
  font-family: var(--font-sans);
}
```

> **Why two layers of font CSS variables?** `next/font` sets `--font-sans-family` (etc.) on the `<html>` element. Tailwind's `@theme` then aliases those into `--font-sans` so utility classes like `font-sans` resolve to the loaded font. Without the alias, `font-sans` would fall back to the browser default.

- [ ] **Step 2: Load fonts in the root layout**

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build-and-test:
    runs-on: ubuntu-latest
    timeout-minutes: 15
    defaults:
      run:

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'
          cache-dependency-path: site/package-lock.json

      - run: npm ci

      - name: Lint
        run: npm run lint

      - name: Format check
        run: npm run format:check

      - name: Type check
        run: npm run typecheck

      - name: Unit tests
        run: npm run test

      - name: Build
        run: npm run build

      - name: Install Playwright browsers
        run: npx playwright install --with-deps chromium

      - name: E2E tests
        run: npm run test:e2e
        env:
          CI: 'true'

      - name: Upload Playwright report on failure
        if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: playwright-report
          path: site/playwright-report/
          retention-days: 7
```

- [ ] **Step 3: Auth.js configuration**

Path: `site/src/auth.ts`

```ts
import NextAuth from 'next-auth';
import Credentials from 'next-auth/providers/credentials';
import { DrizzleAdapter } from '@auth/drizzle-adapter';
import { eq } from 'drizzle-orm';
import { z } from 'zod';
import { db } from '@/db';
import { users } from '@/db/schema/auth';
import { verifyPassword } from '@/lib/password';

const credentialsSchema = z.object({
  email: z.string().email(),
  password: z.string().min(8),
});

export const { handlers, auth, signIn, signOut } = NextAuth({
  adapter: DrizzleAdapter(db),
  session: { strategy: 'jwt' },
  pages: {
    signIn: '/login',
  },
  providers: [
    Credentials({
      credentials: {
        email: { label: 'Email', type: 'email' },
        password: { label: 'Password', type: 'password' },
      },
      authorize: async (raw) => {
        const parsed = credentialsSchema.safeParse(raw);
        if (!parsed.success) return null;
        const [user] = await db
          .select()
          .from(users)
          .where(eq(users.email, parsed.data.email))
          .limit(1);
        if (!user || !user.passwordHash) return null;
        const ok = await verifyPassword(parsed.data.password, user.passwordHash);
        if (!ok) return null;
        return { id: user.id, email: user.email, name: user.name ?? null };
      },
    }),
  ],
});
```
